# Support expiration

This page explains what happens when your **Annual Technical Support** coverage ends.

---

## Your ERP keeps running

When Annual Support expires:

| Action | Happens? |
|--------|----------|
| ERP stops running | **No** |
| Login blocked | **No** |
| Data deleted | **No** |
| Backup/restore blocked | **No** |
| Soviez Cloud contacts your server automatically | **No** |

Expiration affects **commercial entitlements only** — not runtime operation.

---

## What stops when coverage expires

| Entitlement | After expiration |
|-------------|------------------|
| Technical support (covered tier) | No longer included for that License |
| Product updates | No longer authorized for that License |
| Existing installed software | **Unchanged** — continues to run |

You may renew at any time. If you renew **before** expiration, your new term extends from your **current end date**. If you renew **after** expiration, coverage starts from the purchase date.

---

## Monthly legacy subscribers

If you have a **legacy monthly** support subscription:

- Technical support may continue while the subscription is active.
- **Product updates are not included** with monthly support under current product rules.
- To receive product updates, purchase **Annual** Technical Support for the License.

---

## Checking your coverage

In the customer portal **Support** tab, select a License to see:

- Coverage status (active, expired, or not covered)
- Valid until date
- Whether product updates are included
- Whether renewal is available

---

## Updates and your server

Checking whether you are entitled to product updates happens only when **you** initiate an update (for example via the installer in a future release). Your server does not continuously report its status to Soviez Cloud.

See [Privacy and sovereignty](PRIVACY_AND_SOVEREIGNTY.md) for the full data boundary.
