# Offline Mode

## What works without internet

- ERP runtime (after install/activation materials applied)
- Local backup / status / diagnostics / recovery
- Offline Stage authorization packages (signed)
- Offline update apply from signed bundles
- Local SSL inventory operations

## What needs connectivity (connected mode)

- Live SaaS activation
- Registry pull with live tickets
- Live entitlement refresh
- Online migration authorization

## No hidden phone-home

Offline apply paths do not require later network reconciliation to keep ERP running. Reconciliation records receipts when connectivity returns; ERP is unaffected.
