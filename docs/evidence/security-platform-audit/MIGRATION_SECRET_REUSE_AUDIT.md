# Migration secret reuse audit

Desired: new infra secrets fresh; business credentials explicit policy.

Current:
- Staging often recreates disposable PG with fixed `odoo` password
- Production migration can carry source DB (includes Odoo admin hash, tokens in DB)
- Infrastructure passwords for **new** host should be regenerated by `--new`; need explicit gate that **never** copies old PG/master passwords into new docker env without operator policy
- SSH/Registry: Phase 24 Registry ephemeral; SSH not managed by soviez-sh

**Gap:** No formal “refresh infrastructure secrets on migrate” certification test.
