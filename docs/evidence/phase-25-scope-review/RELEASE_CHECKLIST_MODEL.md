# Release checklist model

Checklist items include:
artifact identity/SHA/signatures/provenance/version; clean tests; E2E; security; secret scan; dependency inventory; docs sync; migration/rollback/backup/offline readiness; support/entitlement policy; known limitations; owner decisions; unresolved warnings; Phase 11.5 visual acceptance; publication status; release authorization status.

## Distinct outcomes
```text
ENGINEERING CERTIFIED
READY TO RELEASE
AUTHORIZED TO RELEASE
RELEASED
```

Do not conflate. Phase 25 PASS produces ENGINEERING CERTIFIED (+ checklist evaluation), not RELEASED.
