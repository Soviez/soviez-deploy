# Owner sign-off model

Independent approvals (do not collapse):

| Approval | Required for Phase 25 eng PASS? | Required for public release? |
|----------|----------------------------------|------------------------------|
| Engineering certification acceptance | **YES** (canonical “owner sign-off”) | YES |
| Visual acceptance (11.5) | Per OD-P25-01 (recommended: no) | YES (recommended) |
| Commercial policy acceptance | No | YES |
| Release authorization | No | YES |
| Public artifact publication | No | YES |
| Production rollout | No | Separate |
| Purge authorization | No | Separate forever |

Canonical acceptance “Owner sign-off” is interpreted as **engineering certification acceptance** unless OD expands it.
