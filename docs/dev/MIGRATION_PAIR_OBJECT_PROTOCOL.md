# Migration Pair Object Protocol

Schema `soviez.migration_pair.v1`. Local signed JSON under `$SOVIEZ_MIG_ROOT/pairs/<id>/object.json`.

Always: `migration_token_consumed=false`, `data_transfer_started=false`, `dns_changed=false`, `destination_production_activated=false`, `source_license_active=true`.

No private keys in the object (refs only).
