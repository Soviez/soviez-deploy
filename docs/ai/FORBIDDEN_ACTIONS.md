# Forbidden Actions

Unless the user explicitly authorizes in the current mission:

- commit / push / merge / tag
- deploy / publish / release
- production rollout / DNS cutover / source purge
- alter live customer systems
- regenerate certified `dist/soviez.sh` for docs-only work
- invent `--merge-in` or second engines
- install Webmin/Virtualmin
- kill apt/dpkg to clear locks
- upload customer DB/filestore/business records
